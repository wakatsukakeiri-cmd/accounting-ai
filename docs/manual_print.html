1. 全体の流れ（3分で理解）

本アプリは、紙やPDFの領収書・請求書・通帳・独自帳票をアップロードするだけで、AI（Google Gemini）が自動で仕訳を作成し、弥生会計用CSVやExcelとして出力できるクラウドサービスです。

2. ログイン・会社管理・メンバー招待

👥 複数会社（マルチテナント）の切り替えと作成

1つのメールアドレスで、複数の会社（顧問先・自社グループ）を完全に分離して管理できます。

  • 会社の切り替え: 画面右上のヘッダーにある会社名をクリックし、一覧から切り替えます。
  • 新しい会社を作成: ドロップダウン下の「＋ 新しい会社を作成」をクリックして会社名を登録します。作成したユーザーが管理者（Owner）となります。

✉️ チームメンバーの招待（共同作業）

社内スタッフや会計事務所の担当者を会社スペースに招待できます。

  1. 画面右上の会社メニューから「👥 メンバー管理・招待」を開きます。
  2. 招待したいメンバーのメールアドレスと権限（管理者またはメンバー）を入力して送信します。
  3. 招待されたメンバーが届いたメールの承認リンクを開くと、即座に同じ会社データを閲覧・編集できるようになります。

3. 【最重要】過去帳簿のAI学習設定

💡 なぜ過去帳簿の学習が重要なのか？

会社ごとに「消耗品費にするか事務用品費にするか」「役員個人カードの精算ルール」「取引先ごとの補助科目」などの社内ルールが異なります。 前期の仕訳日記帳を登録しておくだけで、AIがそのルールを自動学習し、次回からの仕訳精度が劇的に向上します。

設定手順

  1. ヘッダー右側の「📚 過去帳簿の学習設定」をクリックします。
  2. 「＋ 新しい帳簿を追加」をクリックし、帳簿名（例:「2025年度 仕訳日記帳」）を入力します。
  3. 前期の弥生会計から書き出した仕訳日記帳CSVまたはテキストファイルをアップロードします。
  4. 「登録して学習」をクリックすると、AIが即座に勘定科目の使い方や補助科目のパターンをインデックス化します。
⚠️ 登録時のヒント: 弥生会計の「仕訳日記帳」→「ファイル」→「エクスポート」から出力したShift-JIS形式のCSVファイルをそのままアップロードできます。文字化けせず自動認識されます。

4. 仕訳作成（3つのアップロードモード）

アップロードする資料の種類に合わせて、最適な解析モードを選択できます。

🧾 領収書・請求書モード

紙のレシート写真やPDF請求書向け

  • 支払先・日付・税込金額・適格事業者登録番号（T番号）をOCR解析
  • 軽減税率（8%・10%）を自動判別
  • 過去帳簿から最適な借方科目を推論
🏦 通帳モード

銀行通帳のコピー・PDF明細向け

  • 預金取引の入出金・残高を時系列で解析
  • 入金（売掛金回収・利息等）と出金（振込・引落等）を自動仕訳
  • 相手科目（普通預金等）を適切にセット
🛠️ 専用モード（カスタム）

特定書式・特殊明細向け

  • 会社独自の資料（売上明細、クレカCSV、EC管理画面）向け
  • ユーザー自身で専用プロンプト（指示文）を自由に定義可能
  • 固定科目や摘要ルールをピンポイント指定

🛠️ 専用モードの作成方法

  1. アップロード画面のモードタブ右端にある「＋ 専用モードを追加」をクリック。
  2. モード名（例：「Amazonビジネス明細用」「Airレジ月次売上用」など）を入力。
  3. 専用の解析プロンプト（AIへの指示）を記述します。
    （例：「この資料はAmazonの購入明細です。書籍は新聞図書費、PC周辺機器は消耗品費に仕訳し、摘要には注文番号を必ず含めてください」）
  4. 「保存」を押すとタブに追加され、次からはそのタブを選んでファイルを投げるだけで独自ルールが適用されます。

5. 仕訳結果の確認・編集・全幅表示

AIが生成した仕訳は、弥生会計の仕訳日記帳と同等の見やすいスプリットビュー画面で確認・編集できます。

👀 分割ビュー（左: 資料画像 / 右: 仕訳表）

左側にアップロードした元の領収書画像やPDFが表示され、右側にAIが作成した仕訳一覧が並びます。元資料を見比べながら検算できます。

✏️ 表の直接編集・行追加・削除

  • 直接編集: 日付、借方科目、貸方科目、金額、税区分、摘要のセルをクリックしてキーボードから直接打ち直せます。
  • 行追加: 表下部の「＋ 行を追加」ボタンで手動で新しい仕訳行を追加できます。
  • 行削除: 各行の右端にあるゴミ箱アイコンで不要な行を削除できます。

🖥️ 全幅表示モード（ワイド表示）

ノートパソコン等の小さな画面で仕訳表が狭く感じる場合は、画面上部の「↔️ 全幅表示」ボタンを押してください。 左側のプレビューが折りたたまれ、仕訳一覧が画面いっぱいに広がり快適に編集・確認できます。再度押すと元の分割表示に戻ります。

6. 弥生会計CSV / Excelの出力・インポート

編集が完了したら、会計ソフトへの取り込みデータを出力します。

📥 弥生会計インポート用CSV出力

弥生会計26の標準フォーマット（Shift-JIS、25列カンマ区切り）に準拠したCSVを一発ダウンロードします。

📊 Excel出力 (.xlsx)

社内チェックや上司・クライアントへの事前確認用に、罫線やヘッダーが綺麗に装飾されたExcelファイルをダウンロードします。

🚀 弥生会計へのインポート手順

  1. 弥生会計を起動し、対象の事業所データを開きます。
  2. メニューバーから「帳簿・伝票」→「仕訳日記帳」を開きます。
  3. 上部メニューの「ファイル」→「インポート」をクリックします。
  4. 本アプリからダウンロードしたCSVファイルを選択します。
  5. インポート形式の確認画面でそのまま「開始」をクリックすると、すべての仕訳が一瞬で登録されます！
💡 エラーが出た場合のチェックポイント: 弥生会計側の勘定科目マスタに存在しない科目名や補助科目名が含まれているとエラーになります。その場合は、事前に弥生会計に科目を登録するか、本アプリの画面上で既存の科目に修正してから再度CSVを書き出してください。

7. 解析履歴の確認と復元

過去にアップロードして解析した仕訳データは、会社ごとに安全にクラウドに保存されています。

  • 画面下部の「📜 過去の解析履歴」に、過去に実行した解析が時系列で保存されています。
  • 「表示」ボタン: 当時の仕訳結果を即座に画面に復元し、再編集やCSVの再ダウンロードが可能です。
  • ブラウザを閉じてしまったりPCが再起動しても、いつでも作業を再開できます。

8. よくある質問 (FAQ)・トラブルシューティング

質問 / 困ったとき 回答と対処法
PDFやスマホの写真がうまく読み取れない ピントがぼけていないか、影や斜めの歪みが強すぎないかご確認ください。また、1ファイルあたりのページ数が多すぎる場合は、数枚ずつに分割してアップロードすると精度が向上します。
弥生会計へのインポート時に科目エラーが出る 弥生会計のマスタに登録されていない勘定科目・補助科目がある可能性があります。画面上で直接セルを編集して既存の科目に修正するか、過去帳簿の学習設定に最新の仕訳日記帳を登録してください。
インボイス（適格請求書）の税区分はどうなる？ 資料上に「T+13桁」の登録番号が記載されているかをAIが自動確認し、適格事業者の場合は通常の課税仕入れ、記載がない場合は免税事業者等からの仕入れ（経過措置等）に応じた税区分候補を提案します。
専用モードを追加ボタンが押せない 会社が選択されているか確認してください。また、権限がメンバーの場合でも追加可能ですが、ブラウザのキャッシュを一度更新（リロード）してお試しください。
アップロードしたデータや領収書の機密性は？ データは暗号化通信で保護され、マルチテナント機能により他社から閲覧することはできません。また、アップロードされたデータがAIの公開学習データに再利用されることはありません。
